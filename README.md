# Supply Chain Visibility System with Optimization Analytics

## Project Overview

This project uses Microsoft Power BI to analyze supply chain operations and support data-driven decisions. It provides insights into sales, inventory, supplier performance, transportation costs, and warehouse efficiency through interactive dashboards.

## Tools and Technologies

* Microsoft Power BI
* Power Query for data cleaning and transformation
* DAX for calculated measures and KPIs
* Microsoft Excel for the source dataset
* Data modeling using a star schema

## Project Milestones

### Milestone 1: Data Modeling and Sales Analytics

* Created fact and dimension tables.
* Established relationships using a star schema.
* Developed sales, cost, profit, and inventory measures.
* Built an initial analytics dashboard.

### Milestone 2: Inventory and Delivery Analytics

* Analyzed inventory levels and delivery performance.
* Created product and regional analysis.
* Developed inventory and delivery dashboards.

### Milestone 3: Supplier and Transportation Analytics

* Evaluated supplier performance.
* Analyzed transportation costs, routes, and carriers.
* Developed advanced KPIs and interactive reports.

### Milestone 4: Warehouse Efficiency and Executive Reporting

* Developed a warehouse efficiency report.
* Created an executive overview dashboard.
* Improved dashboard performance and usability.

## Key Features

* Interactive dashboards and slicers
* Sales, cost, profit, and inventory analysis
* Supplier and transportation performance analysis
* Warehouse efficiency reporting
* Executive-level business insights
